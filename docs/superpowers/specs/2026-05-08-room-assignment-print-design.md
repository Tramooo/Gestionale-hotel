# Room Assignment Print Design

## Goal

Improve the room assignment print layouts generated by `printAssignments(mode)` in `script.js`.

The app has two print modes:

- Standard room assignment printout for clients or front-office use.
- Cleaning printout for housekeeping.

Both outputs must work well when printed in black and white.

## Cleaning Print

The cleaning print is an operational sheet for housekeeping staff. It should prioritize readability at a distance and use the page width aggressively.

Requirements:

- Print in A4 landscape orientation.
- Show one floor per printed page.
- Use very small page margins.
- Make the table fill the available page width.
- Use black-and-white styling only.
- Make the floor label very large, around 32-36px.
- Use large table headers, around 20-22px.
- Use large room/type/note cells, around 22-26px.
- Make room numbers especially bold and easy to scan.
- Keep columns as `Camera`, room type/usage, and `Note`.
- Give the notes column the most width.
- Use clear dark borders between cells.
- Do not stretch rows artificially to fill height when a floor has few rooms.

## Standard Print

The standard print should remain presentable for clients while keeping the existing density.

Requirements:

- Keep two floors per printed page.
- Use black-and-white styling only.
- Make floor numbers larger and more legible, around 20-24px.
- Avoid low-contrast gray floor markers.
- Strengthen horizontal separation between room rows.
- Keep the current dynamic planner columns.
- Make the layout more elegant through typography, spacing, borders, and alignment rather than color.
- Avoid reducing the amount of information shown per page.

## Implementation Shape

Keep the change scoped to `printAssignments(mode)` in `script.js`.

Expected changes:

- Build page groups differently for cleaning mode: one floor per page.
- Keep standard mode page grouping at two floors per page.
- Replace inline cleaning row styles with print-specific CSS classes.
- Add explicit `@page` orientation for cleaning mode.
- Add black-and-white CSS rules for both modes.
- Preserve the existing data flow, assignment lookup, planner columns, and print window behavior.

## Verification

Verify with automated or focused checks that:

- `printAssignments('cleaning')` emits `@page` landscape styling.
- Cleaning mode creates one page block per floor.
- Standard mode still groups two floors per page.
- Standard mode contains stronger row/floor styling classes.
- Existing tests continue to pass.
